# Cascade Method

A cascade is complete only after: invariant → pre-change checkpoint when needed → smallest vertical implementation → deterministic check → counterexample where semantic → repair failures → physical checkpoint.

Unsaved work is not completed work.

Planned sequence: C0 repository/build factory; C1 lifecycle persistence; C2 stream/source cursors; C3 learning/provenance ledger; C4 initiative governor; later sensory/training adapters.
