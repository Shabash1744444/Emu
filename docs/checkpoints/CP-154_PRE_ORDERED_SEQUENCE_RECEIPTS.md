# CP-154-PRE — ORDERED SEQUENCE RECEIPTS
Date: 2026-10-06

Direction decision:
Mobile Nursery remains the compact home/body/learning/sensory/chat environment.
Large surrounding world is deferred to the future PC environment, where rendering and world scale are appropriate.

Immediate goal:
Make L2 sequence tasks causally ordered, not merely final-state checks.

Invariants:
- step order comes from native action receipts;
- UI cannot assert sequence progress;
- wrong-order completion does not count as ordered mastery;
- process restart preserves task and native progress;
- all task learning remains SANDBOX.
