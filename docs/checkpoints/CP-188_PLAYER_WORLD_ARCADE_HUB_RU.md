## Изменения 0.66.1-player-world

| Было | Стало |
|---|---|
| Техническая карточка перед миром | 3D-комната на весь экран |
| Кнопки стрелок и координаты | Джойстик слева, обзор справа |
| Капсула-маркер пользователя | Отдельный человекообразный 3D-персонаж, одежда и рюкзак |
| Общая модель только C4 | Независимый импорт VRM/GLB игрока и отдельное приватное хранилище |
| Удалённый толчок по кнопке | Толчок ближайшего мяча только на расстоянии до 0.85 м |
| Настройки прямо в мире | Выдвижная панель: размер, прозрачность, обзор, цвет, deadzone |
| Фиксированная раскладка | Плавающий/фиксированный джойстик, перемещение кнопок, сохранение |

Геймпад: левый стик — игрок, правый — обзор, A — взаимодействие.
Клавиатура: WASD/стрелки — игрок, пробел — взаимодействие.
Раздельные pointerId для движения и обзора; cancel/blur/visibilitychange
сбрасывают ввод. Во время настройки и вне экрана мира перемещение/такты
комнаты остановлены. Это не остановка автономных тактов самого C4.
Коллизия игрока с границами комнаты и плоскими контурами кровати/стола;
базовая физика сфер сохранена. Это ещё не физическое тело с полноценным
скелетным контроллером, хватанием и контактами мебели для всех объектов.

Новый транспорт `USER_INTERACT` — только проверяемое действие пользователя
в локальном sandbox; не команда организму. `TEACHER_MODEL_CHANGED` и
`teacher_model_*` отделены от `AVATAR_MODEL_CHANGED` / `avatar_model_*` C4.
Ввод игрока не вызывает runtimeCommand или C4VRM.motor.
Существующие исходники ядра, ABI, организм, журнал и стратегия checkpoint
не изменены. Ядро этой сборки не принимает WORLD_EVENT: это видно в
настройках; никаких заявлений об обучении после прогулки нет.

## Проверки и пределы

- Пользователь сообщил, что предыдущая 0.65 запустилась на телефоне;
  это подтверждение запуска, а не всего списка физических испытаний.
- Python PASS: 10 host-тестов, малая явно обозначенная CI fixture.
- Browser PASS: настоящий WebGL renderer, отдельный импорт bundled VRM
  игрока без замены C4, мультитач/cancel, сохранение настроек, два положения
  экрана, возврат в чат, отсутствие runtime-команд от движения игрока.
  Native в этом тесте — изолированный double. Скриншоты относятся к нему.
- Java physics и APK BUILD: результаты соответствующего Actions run.
- PHYSICAL ANDROID нового управления: NOT VERIFIED.

Не готово: графика уровня референса, индивидуально созданная высокодетальная
VRM-модель, полное переназначение нестандартных геймпадов, прыжки/хватание,
общая физика мебели, доставка сенсорики мира в исследовательское ядро.
Персонаж игрока/сферы — пока состояние текущего Android-процесса;
персистентны настройки и импортированная модель. Жизнь C4 хранится отдельно.

## Установка без уничтожения старой жизни

При проверке APK обнаружено: сертификат 0.65 отличается от новой CI-сборки.
Прежний cache `~/.android/debug.keystore` не сохранился (Path Validation Error).
Не удалять 0.65 ради установки новой версии.

0.66.1 имеет отдельный applicationId `com.singularity.c4nursery.world` и имя
**C4 Nursery World**. Старое приложение с его данными остаётся установленным.
Новый workflow явно подписывает кешируемым `ci-signing/debug.keystore`.
Будущие World-сборки смогут обновляться с тем же сертификатом, пока сохранён кеш.
Это development signing; не обещание вечного хранения ключа GitHub Cache.

Для переноса:
1. В старой 0.65 открыть «Система» → «Экспортировать живой .c4m», дождаться сохранения файла.
2. Там же «Сохранить и остановить». Старую установку оставить.
3. Установить World, импортировать прежний Runtime ZIP и **экспортированный** .c4m,
   затем запустить. Не подменять текущую жизнь исходным исследовательским организмом.
4. Сверить journalHead и состояние до экспорта/после импорта в диагностике.

Экспорт .c4m сохраняет собственный журнал и знания ядра. Исходный portable ABI
не переносит весь временный контекст диалога/транспорта, а историю UI-чата
можно экспортировать отдельно. Это ограничение не скрывается. Старое приложение
содержит исходное полное рабочее состояние и остаётся доступным.
Не запускать обе перенесённые копии одновременно, если нужна одна продолжаемая линия.
