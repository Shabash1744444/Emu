# CP-159-PRE — TRUTHFUL AMBIENT SENSORY PRESENCE
Date: 2026-10-06

Goal:
Make mobile sensor/source activity feel alive without conflating host capture with C4 perception.

Required separation:
- HOST CAPTURE ACTIVE != C4 PERCEIVED
- SOURCE STORED != SOURCE INGESTED
- SCREEN STREAM ACTIVE != OBSERVATION
- runtime event presentation must not invent cognition.

UI:
- ambient sensor strip/state;
- host-side capture status;
- separate runtime-ingested/perceived state reserved for real receipts/events;
- no fake "seeing/hearing" animations.
