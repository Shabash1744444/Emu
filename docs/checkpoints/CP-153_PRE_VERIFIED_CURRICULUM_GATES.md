# CP-153-PRE — VERIFIED CURRICULUM GATES
Date: 2026-10-06
Starting point: CP-152 / build #149 green.

Goal:
Introduce capability-gated curriculum progression based on host-verified task outcomes, not XP/reward counters.

Rules:
- LEVEL_1: one object -> one target.
- LEVEL_2 unlocks only after multiple distinct successful LEVEL_1 task signatures.
- failure is retained as an outcome, not punitive score.
- replay cannot increase mastery.
- curriculum state is native and restart-safe.
- SANDBOX mastery never becomes REAL_WORLD evidence.
